# VULCAN — Vacuum UV Optical Characterisation

Built at Nikhef to measure how detector materials reflect light at 
wavelengths where standard tools don't work — vacuum ultraviolet, 
where even air absorbs the beam.

Custom vacuum optical system, Python DAQ and analysis pipeline, 
angle-resolved measurements at 122–230 nm.

**Key result:** First reflectivity measurements of DUNE detector 
components at 128 nm, directly informing detector simulation models 
used across the collaboration.

## Tools
Python · NumPy · Matplotlib · PyQt · DAQ systems
